Entity-Relationship Model

PostgreSQL — five tables (own diagram)

players

  • id PK UUID
  • session_token
  • display_name
  • avatar_id (1–12)
  • interests[3]
  • created_at

queue_entries

  • player_id PK/FK
  • joined_at

questions

  • competition_id
  • question_number
  • question_text
  • 100 × 10 = 1000 rows

matches

  • id PK
  • player1_id, player2_id
  • competition_id
  • current_question, phase
  • status, flag_count
  • end_reason

match_rounds

  • match_id + question_number
  • player1/2_answer
  • player1/2_score
  • flagged / reviewed flags
players 1 — 0..1 queue_entries
players 1 — * matches (as P1 or P2)
matches 1 — 1..10 match_rounds
questions referenced by competition_id + question_number
