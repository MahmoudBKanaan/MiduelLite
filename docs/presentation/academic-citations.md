## Presentation focus (requirement 207)

Emphasise in speech:

1. **Task definition** — problem, objective, requirements  
2. **Planning / process** — Kanban, increments, scope control  
3. **Architecture** — C4, ER, matchmaking, state machine  
4. **Software result** — demonstrated multiplayer full-stack outcome  
5. **Testing & Docker** — evidence of quality and reproducibility  
6. **Reflection** — goal, limits, lessons  

Avoid spending minutes only naming UI controls on each screen. Screenshots support the journey as a **planning/result artefact**, not the main story.
